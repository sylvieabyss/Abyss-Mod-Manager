# Security and private reports

Do not disclose vulnerabilities, credentials, local account-binding records, personal data or private saves in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use its Report a vulnerability control. Until that is confirmed available, request a private contact channel through https://github.com/sylvieabyss without including sensitive details.

No bounty, response deadline or guaranteed support period is promised. Include the affected release, a minimal reproduction using disposable data and the likely impact through the agreed private channel. Ordinary bugs belong in the public issue tracker after personal information is removed.
