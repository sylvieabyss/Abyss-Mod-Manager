# Abyss Mod Manager

A Windows mod-management workbench by **Sylvie Abyss**, with a lavender-and-black interface, profiles, dependency checks, file snapshots, recovery tools and detailed local logs.

This repository is for public documentation, downloads and issue tracking. **AMM is proprietary. Its application source is private.** Third-party components retain their own licenses; see LICENSE.txt and THIRD-PARTY-NOTICES.txt.

## Beta status

The public beta is being prepared. No release is published by this repository preparation. Download only assets attached to an official release after it is published. Do not build AMM from this repository; it deliberately contains no application source or build credentials.

RimWorld and Starsector are the primary tested integrations. Other workspaces have different and incomplete capabilities. Antimatter integration is deferred. This is not a claim of universal mod/save compatibility or complete support for every listed game.

## What to download

Use the Windows x64 installer for a normal installation, or the portable ZIP for an extracted copy. Compare the SHA-256 checksum with SHA256SUMS.txt. The current prepared build is unsigned: Windows may warn or block it. Do not disable antivirus or system protections to run the app. Check the publisher, official release page and checksum first. A checksum detects mismatches; it does not independently authenticate a publisher if both the download and checksum are compromised.

Read LICENSE.txt, PRIVACY.md, the release notes and known issues before installing. Keep independent backups of saves, configuration and mods. AMM's backups and validation reduce risk but cannot guarantee recovery. Draft editing is separate from applying configuration; verify the applied list before launching a game. Steam actions can change subscriptions and downloaded content and require an appropriate signed-in Steam account.
